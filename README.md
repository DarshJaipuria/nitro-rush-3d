# 🏎️ Nitro Rush — 3D Racing Game

A browser-based 3D arcade racing game built with Three.js, featuring AI opponents, drift mechanics, and nitro boost.

---

## 🎮 Playable Demo

A lightweight demo version is available in the `/build` folder.

You can also play it directly on my portfolio website.

---

## 🚀 Features

* AI opponent racing logic
* Drift-based arcade physics
* Nitro boost system
* Particle effects (smoke, trails)
* Lap tracking and race system
* Menu system (track, mode, difficulty)

---

## 🛠️ Tech Stack

* Three.js
* JavaScript
* WebGL
* Custom physics logic

---

## ▶️ Run Locally

> ⚠️ The game uses ES modules, so it must be served via a local server.

### Option 1 — Quick (Recommended)

```bash
npx serve build
```

Then open:

```
http://localhost:3000
```

---

### Option 2 — Python

```bash
cd build
python -m http.server 8080
```

Then open:

```
http://localhost:8080
```

## 🎮 Controls

| Key    | Action        |
| ------ | ------------- |
| W / ↑  | Accelerate    |
| S / ↓  | Reverse       |
| A / ←  | Steer Left    |
| D / →  | Steer Right   |
| Space  | Brake / Drift |
| Shift  | Nitro Boost   |
| Escape | Pause         |
